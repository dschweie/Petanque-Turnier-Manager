Ausführliche Beschreibung

Das getGitter() ist vorberechnet: Jede Position enthält entweder eine Zell-ID (Master-Zelle) oder null (Merge-Slave → kein <td> rendern).

React iteriert das Gitter zeilenweise: 

  gitter[row][col] = "cell-r-c" → <Cell data={zellen["cell-r-c"]} />
  gitter[row][col] = null       → kein <td>

Spaltenbreiten und Zeilenhöhen sind in 1/100 mm (UNO-Einheit); das Frontend rechnet mit Math.round(val / 37.795) in Pixel um.

startZeile und startSpalte geben die absolute Position (0-basiert) der ersten gerenderten Zelle im LibreOffice-Sheet an. Damit lässt sich erkennen, ob der Druckbereich verschoben wurde, auch wenn Größe und Inhalt unverändert sind.

Kopf- und Fußzeile (je links/mitte/rechts) stammen aus dem PageStyle des Sheets; leerer String bedeutet: kein Inhalt oder deaktiviert. Niemals null, damit Gson die Felder serialisiert und das Frontend ein „Löschen" der Kopf-/Fußzeile als solches erkennt (fehlender JSON-Schlüssel wird im Frontend als „unverändert" behandelt).
