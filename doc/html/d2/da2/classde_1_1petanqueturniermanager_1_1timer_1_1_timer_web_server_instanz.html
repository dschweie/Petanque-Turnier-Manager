Ausführliche Beschreibung

Stellt folgende Endpunkte bereit:

  • GET / → timer.html (Vanilla-HTML Countdown-Seite)
  • GET /events → Server-Sent-Events mit TimerSseNachricht als JSON

Implementiert TimerListener – Zustandsänderungen werden vom de.petanqueturniermanager.webserver.WebServerManager delegiert, der einmalig als Listener registriert ist.
