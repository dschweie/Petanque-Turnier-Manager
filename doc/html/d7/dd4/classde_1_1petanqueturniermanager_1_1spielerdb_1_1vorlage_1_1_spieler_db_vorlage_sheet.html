Ausführliche Beschreibung

Spalten A–C sind Eingabe-Spalten (vom User befüllt), D–E werden nach jedem Abgleich vom Tool aktualisiert. Existiert das Sheet bereits, wird es lediglich aktiviert – Inhalt bleibt unangetastet, damit der User seine Daten nicht verliert.
