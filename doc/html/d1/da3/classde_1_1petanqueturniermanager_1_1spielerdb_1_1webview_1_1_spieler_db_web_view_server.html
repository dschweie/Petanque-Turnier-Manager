Ausführliche Beschreibung

Bindet stets an 127.0.0.1 (kein "localhost" wegen IPv6-Doppelresolution, kein 0.0.0.0 aus Sicherheitsgründen) und lässt das OS einen freien Port wählen (Port 0). Ein wiederholter Aufruf von starteOderHole(SpielerDbConnection) liefert idempotent dieselbe URL.
