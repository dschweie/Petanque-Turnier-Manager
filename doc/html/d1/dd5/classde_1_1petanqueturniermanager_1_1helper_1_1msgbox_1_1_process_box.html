Ausführliche Beschreibung

Zeigt Log-Ausgaben, einen Throbber (LO-eigene Spinner-Animation), Statusicons für Erfolg/Fehler, eine Timer-Zeile und eine optionale Hinweiszeile auf eine neue Plugin-Version.

Threading: UI-Mutationen (Property-Set, Sichtbarkeit, Throbber, Auto-Scroll) werden via com.sun.star.awt.AsyncCallback auf den LO-Main-Thread gepostet. Direkter setPropertyValue-Aufruf auf UI-Models/Peers aus Fremd-Threads ist NICHT thread-safe — die UNO-Bridge synchronisiert nur Inter-Prozess-Aufrufe, nicht in-process Java-Calls. Ohne dieses Marshalling kann LO nativ crashen (SIGSEGV im VCL), sobald der Main-Thread parallel Benutzer-Events verarbeitet (Klick im Calc-Fenster, Repaint o.ä.).
