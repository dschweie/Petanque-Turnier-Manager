Ausführliche Beschreibung

Match erfolgt case-insensitiv über das Tripel Vorname + Nachname + Vereinsname. Fehlende Vereine werden beim Import automatisch in der DB angelegt. Doppel-Vorkommen in der Meldeliste werden über denselben Match-Schlüssel zusammengefasst, sodass jeder fehlende Spieler nur einmal importiert wird (mit der Zeile der ersten Fundstelle).
