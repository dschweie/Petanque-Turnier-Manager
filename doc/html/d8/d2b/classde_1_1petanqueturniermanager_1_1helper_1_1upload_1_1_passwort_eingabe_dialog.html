Ausführliche Beschreibung

Zeigt Server-Name, Passwortfeld (Zeichen maskiert) und eine Checkbox zum dauerhaften Speichern in GlobalProperties.

Kann aus einem Worker-Thread aufgerufen werden — der Dialog wird via LoMainThread#post auf den LO-Main-Thread marshalled und blockiert den aufrufenden Thread bis der Benutzer den Dialog schließt.
