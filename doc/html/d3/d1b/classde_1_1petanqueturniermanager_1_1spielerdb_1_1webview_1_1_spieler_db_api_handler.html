Ausführliche Beschreibung

Antworten:

  • GET /api/spieler?q=&limit=&offset= → paginiertes {items, total, limit, offset}.
  • GET /api/spieler/{nr} → einzelner Spieler oder 404.
  • GET /api/vereine, /api/labels, /api/stats.

Kein CORS, da same-origin localhost.
