Ausführliche Beschreibung

Einfache Chunk-Aufteilung: Teams werden nach Rang in Blöcke der Größe maxGruppenGroesse eingeteilt. Die letzte Gruppe enthält den Rest (auch wenn kleiner). Ein 1-Team-Rest wird in die vorherige Gruppe gefaltet, weil eine Gruppe mit weniger als 2 Teams kein KO bilden kann.

List< Integer > de.petanqueturniermanager.algorithmen.common.GruppenAufteilungRechner.berechne ( int anzTeams,
int maxGruppenGroesse,
int minLetzteGruppeGroesse )
static

Ist die letzte Gruppe kleiner als minLetzteGruppeGroesse, wird sie in die vorherige Gruppe gefaltet. Die vorherige Gruppe kann dadurch größer als maxGruppenGroesse werden — Cadrage übernimmt dann den Ausgleich auf eine Zweierpotenz.

Beispiel: 35 Teams, max=16, minLetzte=4 → [16, 16, 3] → 3 < 4 → [16, 19]

Parameter
anzTeamsGesamtanzahl Teams (muss > 0 sein)
maxGruppenGroesseMaximale Gruppengröße (z. B. 16)
minLetzteGruppeGroesseMindestgröße der letzten Gruppe; ist sie kleiner, wird sie in die vorherige Gruppe gefaltet (muss >= 2 sein)
Rückgabe
unveränderliche Liste der Gruppengrößen (Index 0 = Gruppe A usw.)
Ausnahmebehandlung
IllegalArgumentExceptionwenn Vorbedingungen verletzt sind
