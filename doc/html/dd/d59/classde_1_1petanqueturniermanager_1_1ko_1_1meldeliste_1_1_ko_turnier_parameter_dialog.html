Ausführliche Beschreibung

-O.-Meldeliste.

Abgefragt werden:

  • Formation: Tête / Doublette / Triplette
  • Teamname anzeigen
  • Vereinsname anzeigen
  • Anzeige im Spielbaum: Teamnummer / Teamname
  • Bahnnummer im Spielbaum
  • Spiel um Platz 3/4
  • Turnierbaum Gruppen Größe
  • Turnierbaum Min. Rest-Größe
