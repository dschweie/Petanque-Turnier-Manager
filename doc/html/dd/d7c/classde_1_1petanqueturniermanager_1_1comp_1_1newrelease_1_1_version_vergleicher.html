Ausführliche Beschreibung

Verantwortlichkeiten:

  • Normalisieren des Tag-Strings (Strip von führendem v/V, Whitespace).
  • Erkennen von Pre-Release-Markern (-rc, -beta, -alpha, -SNAPSHOT, -pre, -m, jeweils case-insensitiv).
  • Vergleich der normalisierten Versionen via io.github.g00fy2.versioncompare.Version.

Pre-Releases auf der „verfügbar"-Seite werden grundsätzlich nicht als Update gemeldet – wir wollen nutzern nur stabile Releases empfehlen.

Regeln:

  • Ist eine der Versionen null oder leer, wird false geliefert.
  • Ist verfuegbar ein Pre-Release, wird false geliefert – unabhängig vom Versionsnummer-Vergleich.
  • Andernfalls wird semantisch verglichen.
