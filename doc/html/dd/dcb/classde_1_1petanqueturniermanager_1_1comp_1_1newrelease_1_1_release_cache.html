Ausführliche Beschreibung

Eigenschaften:

  • Atomares Schreiben: Daten landen zuerst in einer temporären Datei, dann wird mit StandardCopyOption#ATOMIC_MOVE überschrieben (Fallback StandardCopyOption#REPLACE_EXISTING, falls FS atomic move nicht unterstützt). So bleibt nie eine halb geschriebene JSON liegen.
  • Staleness-Marker: Jeder Cache-Eintrag trägt cachedAt (ISO-8601). ladeWennFrisch(Duration) liefert nur Einträge, deren Alter unterhalb der gegebenen TTL liegt.
  • Korruptions-Recovery: Unleserliches JSON wird in release.info.corrupt-&lt;timestamp&gt; umbenannt und Optional#empty() geliefert – damit der nächste Refresh die Datei sauber neu schreibt.
  • Verzeichnis wird lazy via Files#createDirectories(Path, java.nio.file.attribute.FileAttribute[]) angelegt.
